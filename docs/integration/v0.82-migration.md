# v0.82 production migration

## Scope and provenance

- Upstream stable: v0.82.0, commit `d951ef9df713a3ad3a88645a8c07b79ea5592274` (release verified 2026-10-14).
- Production baseline: `e475e42ec30b28b2032eb814a418d629be8b1afa` on `honjow/InputPlumber:dev`.
- Each of the four v0.81 topic branches was independently rebased onto v0.82.0, tested in an isolated build directory, and merged separately into the candidate. Production integration retains both histories. Old experimental topic branches are preserved remotely but not remerged. The 31 source commits in `v0.81-source-map.json` remain the production feature inventory.
- Production entry remains `dev`. The downstream package remains `SkorionOS/skorion-packages:master/local/inputplumber-git` tracking `dev`. No image manifest changes.
- Backup branch: `backup/dev-before-v0.82-20261014` at the unchanged production baseline. A same-name local tag and verified complete-history bundle also preserve the baseline.

Review corrections were added before the final aggregate pass:

1. Buffered IIO writes a real newline to unbind sysfs triggers and verifies readback; cleanup failure conservatively retains hrtimer ownership. Shared sensor offset fallback is restored with per-axis precedence.
2. Both mapped button transitions preserve 16 ms spacing. The paused-clock queued DOWN/UP/DOWN regression emits at 0/17/33 ms.
3. Invalid upstream cross-file udev GOTO/label were removed. Existing two-stage hide actions and scoped restoration are unchanged; no new permission policy is introduced.

Release build, remote CI and downstream package provenance are recorded separately after publication. This is not a hardware sign-off.

## Hardware and scope limits

No daemon is started in the cloud, and no actual device node permissions or system services are modified. Hardware/firmware behavior, real IMU axes/rates, repeated suspend/resume, UHID/Steam recognition, rumble and touch input remain hardware acceptance items. OXP3 upstream has no touchscreen source configuration; this migration does not invent a device path or orientation.

Historical experimental Go1 HID IMU, OXP userspace initialization/full interception, obsolete MSI driver and legacy unit/timestamp redesigns remain excluded as in the prior production rebuild.
