## Features not replayed

Exact or net-patch upstream absorption: early 8bitdo/HORI/AOKZOE/Claw8, AccelGyro correction, unsigned-axis normalization, final OXP HID implementation. These remain provided by the stable baseline.

Historical experiments are retained in original remote refs but not revived: original Go1 HID IMU/right-hand Center, OXP no-kernel userspace initialization/full interception/vendor rumble, obsolete MSI sysfs driver, old IMU timestamp/unit redesign, and unpublished upstream hidraw/IMU architecture branches. OXP protocol documentation can be extracted separately; gh-pages is not a source branch.

Old BMI resume-trigger fixes are considered selectively only when necessary to preserve the production buffer lifecycle. Other preexisting reliability findings remain separate from the minimum compatibility work; each included fix must state its reason and tests.
